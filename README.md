# Amazon Ad Analysis Tool
Basic open-source version for Amazon seller daily ad data tracking & analysis

## Function
- Upload CSV ad report
- Record daily operation behavior
- Auto calculate ACOS / CTR / CVR
- Generate basic optimization suggestion
- Local SQLite data storage

## Tech Stack
Vue3 + Flask + Pandas + SQLite
